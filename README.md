## Cómo correrlo en local

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Configurar la API Key:**
   Crear el archivo `.env` en la raíz con las variables del proyecto (ejemplo de archivo en `.env.example`):
   ```env
   VITE_API_URL=https://api.restcountries.com/countries/v5
   VITE_API_KEY=tu_api_key_aca
   ```

3. **Iniciar la aplicación:**
   ```bash
   npm run dev
   ```
   Abre automáticamente en `http://localhost:3000/ExploraMundo/`.
